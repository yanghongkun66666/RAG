# learn/00-shell

## AgentX 对照卡

本次功能：
学习版工程外壳与最小管理台

AgentX 前端入口：
知识库管理、文件管理、检索、问答等页面入口

AgentX 后端入口：
RAG 相关 controller、application service、domain service、数据库与 MQ 配置

相关表：
当前阶段先关注基础连接能力，业务表后续再逐步加入

最小真实链路：
项目启动 -> 数据库连接 -> pgvector 可用 -> RabbitMQ 连接 -> 最小管理台入口可访问

这次学习版先简化掉什么：
暂不做具体 RAG 业务能力，只做开发壳子和基础环境

## 任务卡

本次分支：
learn/00-shell

本次目标：
建立学习版项目的基础开发壳子

本次只做：
- 项目基础目录
- git 初始化
- 开发计划入库
- 最小文档与任务卡
- 后续 shell 阶段的工作入口

- 文件上传
- 向量检索
- 问答

开发计划、AgentX 参考项目、当前技能体系

一个能继续迭代的学习项目骨架

学习项目目录清晰，开发计划和任务卡已经进入主项目，可以开始下一步壳子开发

验证方式：
- 检查目录是否存在
- 检查 git 是否初始化
